# JReact Primitives and CSS Subset

JReact provides a typed, CSS-inspired style API instead of parsing CSS text. The
low-level element and style APIs live in `jreact-core` (`CoreElements`). The
Tailwind-inspired scales and helpers live in `jreact-utility` (`UtilityElements`),
and the shadcn/ui semantic color tokens live in `jreact-theme` (`ThemeElements`).
Unstyled primitives such as `Accordion` live in `jreact-primitives`; styled
components are assembled in `jreact-components`.

## Primitive Elements

| Element | Purpose | Children |
| --- | --- | --- |
| `Div` | General-purpose block/flex container, the default layout node. | Any primitives or user components. |
| `Span` | Inline grouping for text and inline content. | `Text`, nested `Span`, and `Icon`. |
| `Text` | Displays a string, including a string produced from a Java value. | None. |
| `Icon` | Paints a Swing `Icon` at its intrinsic size. | None. |
| `Input` | Controlled native `JTextField` overlay. | None. |
| `Select` | Controlled native `JComboBox` overlay. | None. |

Factory methods are available on all three element providers:
`CoreElements.div()`, `UtilityElements.div()`, and `ThemeElements.div()`. The
utility and theme variants add token-aware style methods. User-defined
components remain ordinary Java methods and can compose these elements.

## Supported Style Subset

Styles are declared fluently in Java. A declaration either updates the element's
inline style or a selector-based rule. The API does not parse CSS strings and
does not load external stylesheets.

| Property | Supported values / behavior |
| --- | --- |
| `display` | `flex` (default), `block`, `flow-root`, `grid`, or `none`, passed through to Taffy. |
| `flex-direction`, `flex-wrap` | The Taffy flex enums; defaults are `row` and `nowrap`. |
| `flex-grow`, `flex-shrink`, `flex-basis` | Numeric factors and a `Dimension` basis. Utility helpers include `flex1()`, `grow0()`, and `shrink0()`. |
| `justify-content`, `align-items`, `align-self` | Taffy `AlignContent`, `AlignItems`, and `AlignSelf` values. |
| `width`, `height`, `min-*`, `max-*` | Logical pixels, `auto`, or percentages through `Dimension`. Utility `size()`, `wFull()`, and `hFull()` are available. |
| `gap`, `row-gap`, `column-gap` | Logical pixels or the spacing-token scale (`gap(2)`, `gapX(1)`, `gapY(3)`). |
| `margin`, `padding`, `inset` | Logical pixels, spacing tokens, percentages where applicable, and `auto` for margins. |
| `position` | `relative` or `absolute` through the Taffy enum. |
| `overflow`, `overflow-x`, `overflow-y` | `visible`, `clip`, `hidden`, or `scroll`. |
| `background-color`, `color` | Typed `JColor` values. `color` sets text and icon color. |
| `border-*` | Per-side width, style, and color; `solid`, `dotted`, `dashed`, `hidden`, and `none` styles. |
| `border-*-radius` | Per-corner radius with `BorderRadius` values; utility radius tokens include `borderRadius().sm()/md()/lg()/xl()`. |
| `font-family`, `font-size`, `line-height` | Host font family, logical-pixel size, and normal or explicit line height. |
| `font-weight`, `font-style` | Normal or bold, and normal or italic. Swing cannot provide intermediate weights. |
| `text-align`, `direction` | Taffy `TextAlign` and `Direction` values. |
| `text-decoration` | `underline` or none, painted by the text element. |
| `box-shadow`, `text-shadow` | A single shadow with offsets, blur, and color; no spread, inset, or multiple shadows. |
| `opacity` | `0` to `1`; defaults to `1`. |
| `pointer-events` | `auto` or `none`; `none` removes the element from hit testing. |
| `ring-width`, `ring-color`, `ring-offset` | A JReact focus-ring extension painted outside the border, with an optional gap. Utility `ring()` uses a 3px default. |

Semantic colors such as `background`, `foreground`, `card`, `primary`, `muted`,
`accent`, `destructive`, `border`, `input`, `ring`, chart colors, and sidebar
colors come from the theme layer. The utility layer supplies spacing, radius,
text, and leading scales; palette colors also include the Tailwind-style
`red500`, `slate900`, and similar tokens.

Text measurement and wrapping use Java font metrics and the resolved font
properties.

## Inheritance

CSS-inherited properties resolve from the nearest ancestor element when not set
on the node:

- `color`, `font-family`, `font-size`, `font-weight` (bold), `font-style`
  (italic), `line-height`, `text-align`, `direction`, `text-shadow`, and
  `pointer-events`.

`text-decoration` is treated as inherited in JReact. CSS itself propagates
decorations to descendants rather than inheriting the property; the JReact model
approximates that propagation so a decoration on a container reaches its text
children.

All other properties, including backgrounds, borders, spacing, shadows, opacity,
and rings, apply only to the element where they are declared.

## Inline Style Rules and Selectors

A selector starts a rule on the element where it is declared. Subsequent style
calls write into that rule until `inline()` ends the selector scope. Inline
declarations always win over selector rules.

```java
e.div().className("accordion-trigger")
        .hover().backgroundColor().accent().underline().inline()
        .focusVisible().ringWidth(3).ringColor().ring(0.5).inline()
        .disabled().opacity(0.5).pointerEventsNone().inline();
```

Terminal selectors:

| Selector | Matches |
| --- | --- |
| `hasId(String)` | The node's `id`. |
| `hasClass(String)` | A name in the node's class-name set. |
| `type(Class<? extends Node>)` | The node's class or a subclass. |
| `hover()` | The node is under the pointer. |
| `active()` | The node is pressed. |
| `focus()` | The node currently has focus. |
| `focusVisible()` | Focus came from a keyboard interaction. |
| `disabled()` | The node's disabled flag is set. |
| `notLast()` | The node is not the last element child of its parent element. |

Chained selectors wrap the terminal selector:

| Chain | Meaning |
| --- | --- |
| `parent().hover()` | The node's parent element is hovered. |
| `ancestor().hasClass("group")` | The node has an ancestor element with class `group`. |

A chain consists of zero or more `parent()` / `ancestor()` wrappers followed by
one terminal selector. Components are transparent in the element tree, so
`parent()`, `ancestor()`, and `notLast()` also work across component boundaries.

Rules are stored on the node and re-evaluated when interaction state changes.
Matching rules are applied in declaration order; there is no selector
specificity, component scope, or global cascade. Inline declarations are applied
last. `Selectors` supports no attribute, sibling, universal, `:not`, `:is`,
`:has`, group, `aria-*`, or `data-*` selectors.

## Defined Swing Extensions

`CoreElements.input(value, onChange)` overlays a controlled native `JTextField`.
`CoreElements.select(value, options, onChange)` overlays a `JComboBox` with a
non-empty option list and a selected value from that list. Both support disabled
state, keyboard focus, and an accessible name. `CoreElements.icon(icon)` paints a
Swing `Icon` at its intrinsic size; custom icons that paint with the current
graphics color follow the resolved text color. Utility and theme element
providers expose the same factories with token-aware styling.

## Not in the Subset

The following are not supported:

- CSS files, raw inline CSS strings, global stylesheets, or CSS variables.
- Attribute, sibling, universal, `:not`, `:is`, `:has`, group, `aria-*`, and
  `data-*` selectors; only the terminal and chained selectors listed above exist.
- Pseudo-elements, transforms, transitions, keyframes, and animations.
- Background images and gradients.
- Multiple shadows, inset shadows, and shadow spread.
- Font weights other than normal and bold.
- Viewport-relative and font-relative dimensions; use logical pixels or the
  spacing/font token scales instead.

Grid (`display(grid)` plus grid track properties) and absolute positioning with
insets are available through the layout engine but are not covered by the style
table above. Percentage sizes are supported through the typed `Dimension` API.
